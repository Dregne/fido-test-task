Node це один елемент однозв'язного списку. в ньому value (значення) і next (наступний елемент, в останнього це None).
find_element спочатку йде від head до кінця списку і рахує n.
якщо n 1 або 0 то повертає None.
інакше рахує позицію 2 * n // 3 - 1 (// це ділення без остачі) і ще раз йде від початку до цієї позиції, повертає її value.
внизу створюється список 0 -> 1 -> 2 -> 3 -> 4, для нього виведе 2.
